# Building

The mod is built from shared templates via `scripts/generate.py`. Never edit files under
`build/generated/` directly — they are recreated on every run. Edit `template/`, then
regenerate.

## 1. Generate source trees

```powershell
python scripts/generate.py --all      # all versions
python scripts/generate.py 26.1.2     # one version (all loaders)
python scripts/generate.py 1.21.1 fabric  # one target
python scripts/generate.py --docs     # rewrite docs/VERSION_MATRIX.md only
```

Output lands in `build/generated/<mc>/<loader>/`.

## 2. Build

There are two build modes (see `versions.json` `standalone` flag):

### Root build — Gradle 8.11.1 (1.20.1, 1.21.1, 1.21.11)

The active version is chosen with `-Pmc=` or the `MC_VERSION` env var; defaults to the
first entry in `versions.json` (1.20.1).

```powershell
# 1.20.1 (default; JDK 17)
.\gradlew build

# 1.21.1 / 1.21.11 (JDK 21)
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-21.0.12.8-hotspot'
$env:MC_VERSION='1.21.11'
.\gradlew build
```

### Standalone build — Gradle 9.6.0 (26.1.2, 26.2)

26.x cannot share the root wrapper: ForgeGradle 6 hard-rejects Gradle 9+ (needed by the
root build), and NeoForge/Fabric 26.x require Gradle 9.4+ (and Java 25). Each standalone
entry is generated as a self-contained project with its own wrapper.

```powershell
$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-25.0.4.7-hotspot'
python scripts/generate.py 26.2
Set-Location build\generated\26.2
.\gradlew.bat build
```

## 3. Output

Jars are written to `build/generated/<mc>/<loader>/build/libs/`:

| MC      | Loader   | Jar |
|---------|----------|-----|
| 1.20.1  | forge    | `ore-yield-forge-<version>.jar` |
| 1.20.1  | fabric   | `ore-yield-fabric-<version>.jar` |
| 1.21.x+ | neoforge | `ore-yield-neoforge-<version>.jar` |
| 1.21.x+ | fabric   | `ore-yield-fabric-<version>.jar` |
| 26.x    | fabric   | `ore-yield-fabric-<version>.jar` (plain jar, no remap — 26.1+ is unobfuscated) |

## Toolchain requirements

| Java | Versions |
|------|----------|
| JDK 17 | 1.20.1 |
| JDK 21 | 1.21.1, 1.21.11 |
| JDK 25 | 26.1.2, 26.2 |

`docs/VERSION_MATRIX.md` is generated by `scripts/generate.py` — do not hand-edit it.
